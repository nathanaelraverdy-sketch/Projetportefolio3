Cette page s’ouvre autrement

La page admin a besoin d’un petit serveur qui tourne sur l’ordinateur. Ouverte directement (double-clic sur le fichier, ou « ouvrir dans le navigateur » de WebStorm), elle reste vide.

Pour l’ouvrir :

  • double-clique sur « Ouvrir l’admin.command » dans le dossier du projet,
  • ou, dans WebStorm, ouvre le fichier package.json et clique sur le petit ▶ vert à côté de « admin » (ou de « dev » pour la ville).
